# ML Foundations lifecycle (text alternative)

1. Define problem -> goal, constraints, success metric
2. Understand data -> samples, features, labels, quality, bias
3. Select approach -> rule, supervised, unsupervised, RL
4. Prepare and train -> split, transform, fit parameters or policy
5. Evaluate -> validation, test, metrics, baseline, generalisation
6. Use model -> inference, decision, human review
7. Monitor and improve -> failures, drift, bias, retraining

Failure feedback can return the project to steps 1-5. Semiconductor example: RL floorplanning, evaluated with congestion, timing, power, area, legality, and runtime; limitations include reward mismatch and distribution shift.

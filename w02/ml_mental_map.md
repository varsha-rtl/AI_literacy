# AI/ML mental map (text alternative)

AI (broad field)
- Rule-based and search systems
- Machine learning (learns patterns from data)
  - Classical ML
  - Deep learning (multi-layer neural networks)
  - Learning paradigms: supervised, unsupervised, reinforcement, self-supervised
  - Task types: classification, regression, clustering, anomaly detection, dimensionality reduction, ranking
- Generative AI (produces new content)
  - LLMs (language-focused generative models; commonly transformer-based)

The paradigms describe how learning feedback is obtained. The task types describe the requested output. They are different axes.
